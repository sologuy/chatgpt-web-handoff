# ChatGPT 出图

驱动 Chrome 里**已经登录的** ChatGPT Web 生成图片，并把图直接取回本地文件。
不走 API、不需要 key —— 用的就是你自己那个账号的网页版额度。

```bash
CGIMG=
for root in "$HOME/.claude" "$HOME/.agents" "$HOME/.codex" "$HOME/.hermes"; do
  if [ -x "$root/skills/chatgpt-image-gen/cgimg" ]; then
    CGIMG="$root/skills/chatgpt-image-gen/cgimg"
    break
  fi
done
[ -n "$CGIMG" ] || { echo "请先在项目仓库运行 ./scripts/install.sh --skills image" >&2; exit 1; }

"$CGIMG" "一只橘猫蹲在旧书店的木梯上，午后阳光斜射进来" \
  --style "写实摄影，浅景深" --aspect 3:2 --out ~/Desktop
```

返回 JSON，`images[].path` 就是落盘路径，另有尺寸、文件格式、大小与 SHA-256。
这是前台等待命令，生成时间受网页和账号状态影响。要审查文字或代码，用同仓的
`chatgpt-handoff`；本 Skill 可独立安装，不依赖另一个 Skill 的入口。

## 参数

| 参数 | 说明 |
|------|------|
| `prompt`（位置参数） | 要画什么。**尽量具体**——主体、场景、光线、氛围都写上，含糊的描述容易让它反问 |
| `--style` | 风格：`写实摄影，浅景深` / `水彩` / `等距像素` / `胶片颗粒` … |
| `--aspect` | 画面比例：`16:9` / `3:2` / `1:1` / `9:16` |
| `--ref` | 参考图，可重复。会先上传再出图 |
| `--note` | 追加一句自定义要求，原样拼进提示词 |
| `--out` | 输出目录或文件名，默认当前目录；不覆盖已有文件 |
| `--max` | 最多保存几张，默认 4 |
| `--timeout` | 等待上限秒数，默认 600 |
| `--interval` | 轮询间隔秒数，默认 6 |
| `--keep-tab` | 跑完不关标签页（想继续在网页上追改图时用） |
| `--allow-model-drift` | 明确接受实测模型不在预期列表；不要为绕过报错自行加上 |

**档位固定极高，没有参数可调。** 出图这件事没有省额度的必要，来回调档反而多一次
账号级写操作，还可能和别的自动化撞车。

---

## 提示词是自动包装过的

你给的描述会被包成一句明确的出图指令，末尾固定加上：

> 直接出图，不要向我提问、不要先描述你打算怎么画。只要图。

这句不是客套。ChatGPT 对含糊的描述习惯**先追问**风格或尺寸，一问就卡在那儿，
自动化这边只能干等到超时。所以宁可把要求写死。

即便如此，描述太抽象时它仍可能反问。超时返回里会带 `assistant_text`。
先检查保留的会话：已经发出的任务可能仍在生成，不能把超时当作未发送而直接重投。

---

## 会不会打扰你

会在已有 Chrome 会话里新开本次任务的标签页，不主动把 Chrome 窗口提到前台。
浏览器内的标签选择仍可能变化。成功时只关闭本次新页；加 `--keep-tab` 可保留。
失败时保留已经创建的本次页面，返回 `page_id` 和已知的 `conversation_url`，便于核查。

## 出错怎么办

| 情况 | 含义 | 怎么办 |
|------|------|--------|
| `send_unknown` | 已跨发送边界，未确认结果 | 检查保留页面，**不要直接再执行 cgimg**，避免重复生成 |
| `timeout` | 已发送，尚未取得完整图片 | 读取 `assistant_text` 并检查保留会话；可能仍在生成，不能据此重投 |
| `image_download_failed` | 部分或全部图片取回/写盘失败 | 保留 `images` 中已成功的文件，核对 `failed_images`，从现有会话取图，不能重新生成冒充重试下载 |
| `ref_not_found` | 参考图路径不对 | 改路径。这一步在开浏览器之前就查，不浪费一轮 |
| `output_exists` / `output_type` | 输出文件已存在或扩展名不支持 | 换输出路径，保留已有文件 |
| `auth_required` | ChatGPT 掉登录了 | 去原浏览器登录后再执行 |
| `model_changed` / `effort_not_found` | 模型或档位不符 | 报出实测值，不静默降档；明确接受新模型后才可用 `--allow-model-drift` |
| `browser_busy` / `effort_drifted` | 本次未发送，另一入口占锁或档位变化 | 核对未发送状态后可重试 |

**失败时已创建的标签页保留**，成功才自动关掉。判断是否跨发送边界看
`send_attempted_at` 和错误提示；未知状态不能自动重发。部分保存失败返回 `ok: false`，
不把已存几张图说成全部成功。成功后的 `tab_closed` 说明是否确认关闭本次页面。

## 注意事项

1. **需要现有 Chrome 开着远程调试端口且已登录 ChatGPT。** 先在仓库运行
   `./bin/cgh doctor` 检查；连接失败时报告现场，不擅自重启浏览器或更换 Profile。

2. **这是网页版额度，不是 API。** 跑得多会撞你自己账号的出图限额。

3. **与 `chatgpt-handoff` 共用提交短锁。** 只锁设档位、复验、发送与对话 URL 确认，
   生成和下载阶段不占锁。这不提供批量或并发调度，也不能防止用户手动修改账号档位。

4. **图在原页面内 fetch 取回**，浏览器使用现有会话；不读取、复制或保存 cookie。
   只识别助手消息中渲染出的生成图，排除用户上传的参考图；等待生成结束且图片出现后再取图。

5. **参考图会先上传。** 上传的是原图，注意别把不该外传的图当参考图丢进去。
